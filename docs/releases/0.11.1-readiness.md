# codr 0.11.1 readiness

## Scope and compatibility

Prepare 0.11.1 from published 0.11.0 source
`f8fe9da5b739042c335708ec65775581ee836b8d`, plus the scoped changes in the
[release notes](0.11.1.md). Keep unrelated Foreman/sharing, recovery and encryption
experiments in the separate main checkout out of this release.

The Cargo package, its own lockfile entry and Herdr plugin agree on 0.11.1.
Dependencies, the MDK 0.14 source pin, control protocol, bridge state version,
runtime layout and storage cohort are unchanged. There is no account migration.
Fresh identities still use supported 0.9.0 setup before the explicit combined
handover. Existing `/update` confirmation and cold-backup requirements remain.
