# codr 0.13.0-preview.1

Opt-in shared-room onboarding.

Stable/latest is unchanged. Requires fresh packages from
this exact source; 0.12.2 assets cannot be reused or relabelled.

This is fresh-room onboarding, not an upgrade or migration path. Stable update
offers remain stable-only; previews require explicit opt-in installation.
Package CI and isolated fixtures do not establish real Mac room interoperability;
verify normal input and its correlated reply after installation.

- One OS-neutral instruction to the coding agent, backed by fresh macOS helpers.
- Fresh-only transport bootstrap, signed invitation, exact target verification,
  full explicit owner roster choices, new dedicated native session/claim and no
  bridge discovery until strict attachment. No private-history conversion.
- Versioned preview package includes the normal-Enter adapter, dependency
  licenses and SHA-256 source/executable evidence. Object-header platform checks
  and compiled version/source/target checks precede activation. Fresh setup
  reserves native ownership durably before creation/discovery, including crashes.
  Python 3.9 binary installation remains
  supported; Rust/Bun/Node/Homebrew are not installation dependencies.
- Project-only adapter configuration and dedicated launchd/foreground arguments.
  Existing accounts, services, settings, permissions and human cards stay intact.
- Empty invocation grants even for owner; agent budget remains disabled until
  explicitly enabled. Existing roster holds, stop, deduplication and uncertainty
  boundaries are retained.

See [agent installation](../AGENT-INSTALL.md). Windows has an independent runtime
candidate and must not be advertised as verified by this Mac change. Existing
Linux/both-Mac/standalone-connector package gates remain required. Bun adapter
fixtures join Linux/Mac checks. Preview tag publication uses `--prerelease
--latest=false`; there is no worker publication, installation or live validation.

MDK 0.19 migrated storage must not be opened by older runtimes. This is not an
upgrade/migration path for existing cohorts or approval to restart any service.
